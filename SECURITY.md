| Vendor App | `v16.6.x` | :white_check_mark: |

---

## Reporting a Vulnerability

We take the security of Drozio and its users very seriously.

If you find a security vulnerability, please do **NOT** open a public issue. Instead, report it privately:

1. **Email:** Send details to the repository administrator or security team at `security@diploy.space`.
2. **GitHub Security Advisory:** Submit a private vulnerability report via the [GitHub Security Advisory Tab](https://github.com/Diploy-Space/Drozio/security/advisories/new).

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or proof-of-concept code/request payloads.
- Any suggested remediations if available.

We will acknowledge receipt of your vulnerability report within 48 hours and provide regular updates on the resolution.
